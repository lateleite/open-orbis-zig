# open-orbis-zig

open-orbis-zig is an ***in development*** Zig package for interfacing and packaging applications for the PlayStation 4 through the [OpenOrbis SDK toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain).

Zig 0.17.0's development version is required.

**WARNING**: usage of this package has some caveats: 

- You must have a build of [OpenOrbis SDK toolchain](https://github.com/OpenOrbis/OpenOrbis-PS4-Toolchain) tools in file system, with the environment variable `OO_PS4_TOOLCHAIN` pointing to their root directory.

- It depends on Zig patches that haven't been submitted or merged yet!

**Features**:

- Zig modules exposing system APIs with safe types and errors
- On-demand, self-contained [OpenOrbis musl](https://github.com/OpenOrbis/musl) compilation support
- PS4 fake-SELF and packaging utilities for your Zig build scripts

## Installing as a `build.zig.zon` package

Run in your Zig project:
```sh
zig fetch --save git+https://github.com/lateleite/open-orbis-zig.git
```

Then in your `build.zig` file:
```zig
pub fn build(b: *std.Build) !void {
    // ...

    // Add a reference to the package you've just fetched...
    const dep_orbis = b.dependency("open_orbis_zig", .{
        .target = target,
        .optimize = optimize,
    });

    // to use the system API wrapping module:
    const mod_orbis = dep_orbis.module("orbis");
    // ...then in your executable or library module
    my_module.addImport("orbis", mod_orbis);

    // to link the musl libc:
    const lib_musl = dep_orbis.artifact("musl");
    // ...then in your executable or library module
    my_module.linkLibrary(lib_musl);

    // to link system libraries to your module:
    const wf_syslibs = dep_orbis.namedWriteFiles("sys_libs");
    // ...then in your executable or library module
    my_module.addLibraryPath(wf_syslibs.getDirectory());
    my_module.linkSystemLibrary("kernel", .{});
    my_module.linkSystemLibrary("SceGnmDriver", .{});
    my_module.linkSystemLibrary("SceVideoOut", .{});
    // and any other modules you wish

    // make sure to ALWAYS set this linker script in your executable,
    // or else it will be invalid on Orbis OS
    exe.setLinkerScript(dep_orbis.path("link.x"));

    //
    // packaging steps
    //
    const EBOOT_PATH = "eboot.bin";
    const GP4_PATH = "pkg.gp4";
    const SFO_PATH = "sce_sys/param.sfo";
    const CONTENT_ID = "IV0000-ZIGG00001_00-ZIGTEST000000000";
    const PKG_NAME = CONTENT_ID ++ ".pkg";

    // create fakeself eboot.bin out of new executable
    const eboot_file = orbis.createFself(b, exe, .{});

    // create param.sfo describing program's package
    const sfo_file = orbis.createSfo(
        b,
        dep_orbis,
        b.path("sce_sys/param.sfo.zon"),
        SFO_PATH,
    );

    // generate pkg.gp4
    const gp4_file = try orbis.createGp4(b, CONTENT_ID, &PKG_ASSETS, .{});

    // build the PKG itself
    // depends on eboot.bin, param.sfo, pkg.gp4 and other assets
    const wf_pkg = orbis.setupPkg(b, &PKG_ASSETS, .{
        .eboot_file = eboot_file,
        .gp4_file = gp4_file,
        .sfo_file = sfo_file,
    });
    const pkg_cmd = orbis.createPkg(b, wf_pkg);

    // install the new PKG
    const install_pkg = b.addInstallFile(wf_pkg.getDirectory().path(b, PKG_NAME), PKG_NAME);
    // depend on the pkg itself
    install_pkg.step.dependOn(&pkg_cmd.step);
    // add PKG installation to install step
    b.getInstallStep().dependOn(&install_pkg.step);

    // add eboot.bin to install step,
    // useful for emulators
    const install_eboot = b.addInstallFile(wf_pkg.getDirectory().path(b, EBOOT_PATH), EBOOT_PATH);
    install_eboot.step.dependOn(&pkg_cmd.step);
    b.getInstallStep().dependOn(&install_eboot.step);

    b.installArtifact(exe);

    // ...
}
```
